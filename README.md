# 英语学习助手

当前版本：**1.8.0**

## 功能

- Edge：选中网页文字后，自动显示“朗读”和“中英翻译”按钮。
- Codex：在正文中选中文字后，自动显示同样的按钮。
- Edge 与 Codex 的英文朗读统一使用本地离线的 Ryan High 美式男声。
- 中文继续使用 Windows 中文语音。
- 翻译优先调用本机安全配置的腾讯云机器翻译；未配置、额度耗尽或服务不可用时自动回退到本机已登录的 Codex。
- Edge 仅通过 `127.0.0.1` 与本机助手通信，不依赖浏览器原生消息注册。

## 安装

安装前需要：

- Windows 10/11
- 已安装并登录 Codex CLI
- Python 3.9 或更高版本
- 使用 Git 克隆时需要 Git LFS（用于 Ryan High 语音模型）

1. 双击 `安装英语学习助手.cmd`。
2. 在 Edge 地址栏输入 `edge://extensions`。
3. 打开左侧的“开发人员模式”。
4. 点击“加载解压缩的扩展”。
5. 选择本项目中的 `edge-extension` 文件夹。

首次安装会在项目内创建独立的 Python 虚拟环境并安装 Piper 语音组件，并在桌面创建“英语学习助手”快捷方式。助手不会随 Windows 登录自动启动；需要时双击桌面快捷方式手动开启，关闭或重启 Codex 不会让已运行的助手退出。

## 使用

### Edge

在网页中选中英文或中文，点击文字旁边的“朗读”或“中英翻译”。
点击翻译后会立即显示“Codex 翻译中…”等待提示，完成后自动替换为译文。

### Codex

在聊天正文中拖动选中文字或双击选词。操作窗口固定显示在选区正下方，并可直接切换慢速、正常或快速朗读。助手只通过 Windows UI Automation 的只读文字选择接口识别选区；后台识别不会读取、改写或清空系统剪贴板，也不会模拟 `Ctrl+C`。只有你主动点击译文窗口中的“复制”按钮时，助手才会把译文写入剪贴板。

## 设置

- Edge：在网页选区工具条中直接切换慢速、正常或快速朗读；扩展选项只保留网页悬浮按钮开关。
- Windows 助手：右键任务栏通知区域图标，可切换语速、暂停自动识别或退出。
- 手动开关：双击桌面的“英语学习助手”开启；右键任务栏通知区域图标并选择“退出”关闭。重复双击不会启动多个实例。
- 腾讯云快速翻译：先开通腾讯云机器翻译并创建仅允许机器翻译操作的 CAM 密钥，然后双击 `配置腾讯云翻译.cmd`，在本机输入 SecretId 和 SecretKey。密钥由 Windows 当前用户 DPAPI 加密保存，不会进入源码或 GitHub。

## 隐私与额度

- 英文朗读使用本地 Piper Ryan High 模型，中文使用本机系统语音；朗读内容不会发送到外部服务。
- 只有点击“翻译”后，选中文字才会交给腾讯云；未配置腾讯云、免费额度耗尽或腾讯云不可用时才会交给 Codex。
- 只有回退到 Codex 的翻译才会启动临时 Codex 任务并消耗 Codex 使用额度。
- 临时任务不会保存为普通 Codex 对话。

## 卸载

1. 双击 `卸载英语学习助手.cmd`。
2. 在 Edge 的扩展页面删除“英语学习助手”。
